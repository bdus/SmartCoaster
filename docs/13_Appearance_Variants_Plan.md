## 2. 冻结清单（外观变体不可改动）

> 这些值来自 `mechanical/square_v1/cad/square_model.py`；外观变体只能换“外皮”，不得改这些功能几何。

| 类别 | 冻结项 | 值 |
|---|---|---|
| 总体 | 总高 / 浮动 | 18.0 mm（底壳 14.5 + 间隙 0.5 + 顶板 3.0）；**0.5 mm 浮动缝**不可变 |
| 称重 | 传感器 / 安装 | HY928D 34×34×1.0 @ z=5.0；4 角 boss Ø6（z=5.0）；Ø3.1 孔 @28×28；中心 Ø5 |
| 称重 | 传力柱 | Ø6，z=6.0→15.0；中央垫块 Ø12×0.8 |
| 称重 | 过载限位 | 0.5 mm 处壳口先接触（≈150% / 7.28 kg）；接触体积 ~30.5 mm³ |
| 电气 | PCB | 93.2×93.2×1.6、R6、38×38 开口、80° C 口、4×M2 @(±40,±24)、z=5.0 |
| 电气 | OLED | 模组 38×12×1.2；**可视窗 26×7、中心 x=−8、窗中心 z=8.0**；可视区 22.4×5.6 必须无遮挡 |
| 电气 | 按键 | Ø8.2、中心 x=17、z=7.2；行程内不得被裙边遮挡 |
| 电气 | USB-C | 后缘居中（8.94×7.5×3.26、z=6.6），插头/线缆可达 |
| 电气 | 电池 | 25×30×5 @(−32,24)；固定/绝缘方案仍待补（M2） |
| RF | 天线净空 | U1 @(29,32)，天线朝后缘；**天线正上方不得有金属**（或必须实测证明可用） |
| 外观 | 无灯 | 不得引入 LED/光导/灯缝（用户决定） |
| 装配 | 外皮不得跨越浮动缝 | 外观件不得连接顶板与底壳（否则成为称重旁路） |

## 3. 允许变化（外观轴）

| 轴 | 允许范围 | 约束 |
|---|---|---|
| 外轮廓 | 方形 R8 / 方圆（R20–R40）/ 倒角 / 胶囊（在 ≤110×110 包络内） | 必须能包住冻结内核；包装（120×120×36）与手掌/桌面稳定性复核 |
| 顶板表面 | 铝阳极氧化 / PC+PCR / 玻璃贴面 / 双色 | 金属面积与天线关系要复核；材质必须与 `meta.json`/`docs/10` 一致 |
| 窗 | 矩形/圆角矩形/椭圆 bezel；玻璃烟灰/清透；齐平/微凹 | **26×7 可视区**不可缩；不得遮挡 |
| 按键帽 | 颜色/材质/高度/亮面或哑光 | 开孔 Ø8.2、行程、裙边 clearance 不变 |
| 底壳 | 分模线位置、腰线、垫脚、配色 | 不得跨浮动缝、不得封死 USB-C/散热 |
| CMF | 4 个既有变体（Lumen Violet / Moss / Sand / Graphite）+ 新色 | 与 `docs/10`、渲染、包装一致 |
| 表面细节 | logo、倒角、蚀刻、纹理、腰封 | 不增加称重旁路、不影响清洁 |

## 4. 圆形可行性结论（重要）

- 方形 PCB 对角线：`93.2 × √2 = 131.8 mm`。
- 圆形外壳要容纳它，直径至少 `131.8 + 2×2.4（壁）+ 2×0.8（间隙）≈ 138 mm`；而当前产品目标是 Ø110。
- 因此：
  1. **“近似圆”可行**：100×100 内的 squircle / 大圆角/胶囊，包络不变、PCB 不变、功能不变（推荐）。
  2. **“真圆”不可行（纯外观）**：必须新做圆形 PCB（C 环 Ø102 一类）并重新跑 ERC/DRC/DFM + 机械装配 + 固件引脚——属于“结构与功能变更”，应单独立项，不能混在“只改外观”里。
  3. LUMEN 的圆形外观语言（曲面、比例、悬浮缝）可以借鉴，但其内部（光导/LED/0.49" 屏/无按键/17 mm）不可复用。

## 6. 每个变体的验收流程（必须逐条过）

1. **代码结构**：把 `square_model.py` 拆成 `build_internals()`（冻结）+ `build_skin(params)`（可变），或新增 `mechanical/appearance/<variant>/skin.py` 只覆盖 shell/plate/bezel。
2. **不变量 diff**：与基线对比功能区坐标（传感器/boss/传力柱/PCB/电池/OLED/按键/USB-C），容差 0。
3. **功能自检**（复用 square_v1 的 21 项，去掉纯外观项）：浮动 0.5、行程无遮挡、过载先接触、37 对干涉 0、STEP 回读。
4. **外观专项检查**：窗可视区/视角、按键可达性、USB-C 插头空间、天线净空（金属面积/距离）、外轮廓包络与包装、桌面稳定性、清洁可达性。
5. **渲染**：用同一版 STL/CMF 出 hero/front/exploded（`render/RENDER_LOG.md` 记录）。
6. **独立复核**：verifier 只读复跑（几何 + 渲染 + 文档一致性）。
7. **文档**：更新 `docs/10`（CMF/外观口径）、`docs/07`（状态）、`HANDOFF`、README；commit。
