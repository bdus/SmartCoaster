# 产品路线：先“能用”，再“红点级”

> 2026-11-04 起。G0（可行性）已完成；下面按 **P1 可用 → P2 可制造 → P3 红点级** 迭代。

## P1 — 能用（当前目标）

**功能**
- [ ] PCB 0 short / 0 unconnected；ERC/DRC 干净（丝印可豁免，需记录）。
- [ ] 手板：ESP32-S3 + 0.91" 屏 + HY928D + HX711，按 `docs/05` 矩阵测。
- [ ] 砝码标定：零点、量程、重复性、噪声、温漂记录。
- [ ] 固件：BLE GATT、NVS/跨日、低功耗休眠、OLED 中文。
- [ ] 整机装配：四角凸台共面、+y 预紧、浮动间隙 0.156 mm 余量、限位。
- [ ] 连续 7 天饮水记录不丢数、不误触发。

**外观（可用级）**
- [ ] 前脸：屏 26×7、键 x=17、halo 均匀（当前 LED 位置需复核）。
- [ ] 顶板/底壳配合、无段差、按键手感。
- [ ] 3D 打印首件（外壳 + 顶板）验证屏/键/传感器配合。

## P2 — 可制造

- [ ] PCB 层数决策：2 层（成本）vs 4 层（内层 GND/电源，HX711 模拟更干净、布线更稳）。
- [ ] LED/灯导位置与 halo 均匀性（D1/D2 当前远离屏窗，需移到窗两侧或改导光）。
- [ ] DFM：线宽/间距/孔环/阻焊桥；Gerber/钻孔/BOM/坐标文件。
- [ ] EMC/ESD、USB-C、充电、电池保护。
- [ ] 外壳公差、卡扣/螺钉、防水/防滑、跌落。
- [ ] 认证评估（CE/FCC/ RoHS）与包装。

## P3 — 红点级

- [ ] CMF：阳极氧化铝/深紫哑光、石墨灰、荧光绿点缀；材质样板。
- [ ] 光：360° halo 均匀、无热点；屏幕 UI 字体/动效/水位动画。
- [ ] 细节：分模线、logo、隐藏螺钉、导光条、按键字符。
- [ ] 交互：单击看进度、放杯/拿杯事件、提醒节奏、App 视觉。
- [ ] 叙事：场景图、爆炸图、包装、可持续材料说明。
- [ ] 评审：红点申报材料（照片/渲染/说明）。

## 当前 PCB 状态（2026-11-04）

- 自动布线（Freerouting 2.5，2 层）：844 track/via。
- 规则调整为 min track 0.18 / edge 0.25 后：**62 violations + 15 unconnected**；已删除短路（0 short）。
- 剩余：15 unconnected（LED/3V3 区）、18 dangling（stub）、44 丝印、5 阻焊桥。
- 根因：D1/D2 两颗 RGB 放在板两侧、离前脸屏窗远，LED 网在 2 层里跨板；且与 halo 位置不符。
- 下一迭代（建议）：**把 D1/D2 移到屏窗左右两侧 + 重布线**；若仍挤，改 **4 层**（内层 GND/电源）。

## 判定

- “能用”：P1 全部勾选 + 手板 7 天数据。
- “红点级”：P1/P2 完成 + P3 的 CMF/光/细节/叙事达到可送审质量。
