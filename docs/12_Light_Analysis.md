# 光导耦合与均匀性（P3）

## 1. LED 与光导

- D1：5050 RGB，20 mA/色，典型 **2–3 lm/色**（红/绿/蓝）。
- 光导：PMMA，2×2 mm，路径 57 mm；体透过 0.92^5.7 ≈ **0.62**；两次折弯 ≈0.90；端面/侧面出光 ≈0.80 → 总效率 ≈ **0.45**。
- 单色输出 ≈ 2.5 lm × 0.45 ≈ **1.1 lm**。

## 2. 发光面

| 区域 | 面积 |
|---|---:|
| 窗周 halo 框（0.8×(2×26+2×7)） | 53 mm² |
| 前缘上灯线（23×1.5） | 34.5 mm² |
| 底部灯线（40×1.5） | 60 mm² |
| 合计 | 148 mm² |

- 平均亮度 ≈ 1.1 lm / 148 mm² ≈ **7,400 lm/m²**；Lambertian 近似 ≈ **2,400 cd/m²**（白天可读，夜间明显）。

## 3. 均匀性对比

| 方案 | 出光点 | 估算 max/min | 成本 |
|---|---|---:|---:|
| 单点（仅左上灯线） | 1 | ~3.0 : 1 | 0 |
| **Y 光导（左上 + 底部）** | 2 | **~1.4 : 1** | +¥0 |
| 双 LED（左右各一） | 2 | ~1.2 : 1 | +¥1.2 + D2/R22–24 + 重布线 |

- 结论：P3 采用 **Y 光导**（单 LED、两路出光、零 BOM 增加）；双 LED 留作 P4，如果实测 < 1.3 不达标。
- Y 光导已进 CAD：`mechanical/square_v1` 13 件、`verify_v01.py` **21/21**；新增底部灯线 + 前部 Y 分光。

## 4. 实测方法

- 暗室，手机照度计贴 4 个框边 + 2 条灯线，读 lux；max/min 即均匀性。
- 记录到 `tests/handboard/BRINGUP_RECORD.md` §4；若 < 1.3 则 P4 上双 LED。
