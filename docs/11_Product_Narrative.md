# 产品叙事（Red Dot 评审用）

## 一句话

**一杯水，一块杯垫，一个不需要你盯着手机的理由。**

## 问题

- 提醒喝水的手环/手机通知被忽略，因为它们在“另一个屏幕”上。
- 杯子本身不知道你喝了多少；量杯/APP 记录都要求额外动作。
- 桌面上的杯垫是唯一“一直在场”的位置，却只承担隔热。

## 洞察

喝水是一个**放下杯子**的动作。把称重放进杯垫，喝水这件事就自动被记录，不需要打开任何东西。

## 设计

- **重量即输入**：放杯 → 识别杯重 → 拿起来喝 → 放回 → 差值即这一口；续水不计入。
- **三种状态**：空杯/喝水/秤；单击看重量，双击手动切模式，长按 2 s 设杯，长按 5 s 配对。
- **屏而不是声音，也不是灯**：该喝水时 26×7 窗口轻提醒，不打断会议；目标达成时屏上完成动效 3 s。
- **前脸克制**：只有 26×7 屏窗 + 按键，没有灯环、没有灯带；唯一缝隙是顶板-底座 0.5 mm 浮动缝（秤的行程缝）。
- **屏只在你需要时亮**：26×7 窗口，8 s 息屏；中文“今日 1250 / 该喝水了 / 刚喝 50”。
- **7 天续航**：PM light sleep + BLE 占空广播；USB-C 充电。

## 体验

1. 第一次：放上空杯 → 长按 2 s 记住杯重 → 放回杯子。
2. 每天：喝水自动累计；该喝水时屏上轻提醒；单击看今日进度。
3. 同步：长按 5 s → 手机 App 在 120 s 窗口内连接 → 读今日/设目标/设时间；断开即关广播。

## 可持续

- 30% PCR 外壳、FSC 纸浆模塑、无胶卡扣、可换电池、可维修（4 颗 M2）。
- 无云：数据只在本地与手机之间。

## 规格

| 项 | 值 |
|---|---|
| 尺寸/重量 | 100×100×18 mm / ~155 g |
| 量程 | 5 kg（HY928D + HX711，24 bit） |
| 目标 | 2200 ml/日（App 可改） |
| 显示 | 0.91" 128×32 OLED，26×7 窗口 |
| 反馈 | 仅屏幕显示；无 LED、无灯带 |
| 电路 | 43 器件 / 28 网络（无 LED 驱动） |
| 连接 | BLE 5（NimBLE，0xFF00 服务） |
| 电池 | 500 mAh，7 天级 |
| 充电 | USB-C |
| 材料 | PC/ABS + PMMA + 硅胶 |

## 评审关键词

**Invisible input（无感输入）· Ambient feedback（环境反馈，仅屏幕）· Repairable（可维修）· Local-first（本地优先）**
