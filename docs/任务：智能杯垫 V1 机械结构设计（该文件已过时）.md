# 任务：智能杯垫 V1 机械结构设计

你是一名机械结构工程师，负责设计一款可实际加工、装配和验证的智能称重杯垫。

使用 AgentCAD + build123d 进行参数化建模，后续可使用 FreeCAD 检查装配、干涉和工程图。

## 一、产品目标

设计一款简洁、现代、适合家庭使用的智能杯垫。

核心功能：

- 测量杯子及水的重量变化。
- 通过重量变化判断饮水行为。
- 配合手机记录饮水数据。
- 普通版带一块小尺寸 OLED 屏幕和一个实体圆形按键。
- 后续规划无屏 Solar 版本。

## 二、外观基线

初始尺寸：

- 长度：100mm（参数化）。
- 宽度：100mm（参数化）。
- 总厚度：待评估，优先控制在合理的家居产品尺度。
- 外壳：白色或浅灰色。
- 四角：圆角过渡。
- 表面：平整、简洁、便于擦拭。
- 顶板：可拆卸或便于维护。

屏幕和按键：

- 小尺寸 OLED，不使用大面积显示屏。
- OLED 位于杯垫前缘右侧区域。
- 圆形实体按键与 OLED 处于同一水平线上。
- 屏幕与按键都不得参与称重受力。
- OLED 尺寸、开孔尺寸和按键尺寸全部参数化。
- 预留屏幕排线和按键连接线的安全通道。
- 屏幕不得与杯子底部区域发生干涉。

## 三、称重传感器：HY928D

使用我提供的 HY928D 图纸和实物信息。

已知图纸信息：

- 外形约 34×34mm。
- 四个安装孔，孔径约 Ø3.1mm。
- 孔中心距约 28×28mm。
- 侧面厚度标记 H，但尚未确认具体数值。
- 图纸中存在中央区域及受力相关标记。
- 饮水杯及水的重量预计不超过 1kg。
- 当前优先考虑 5kg 量程。

重要约束：

1. HY928D 是片状应变传感器，不要直接将它等同于常见的单点式铝合金梁式称重传感器。
2. 不得凭外形猜测内部应变梁、弹性区域、固定端或受力端。
3. 不得擅自认定四个安装孔全部固定，或中央区域一定是受力点。
4. 不得根据其他型号的传感器结构推断 HY928D 的受力方式。
5. 先根据图纸、实物照片和供应商资料分析可能的安装方式。
6. 将尚未确认的机械尺寸、接触面、安装方向、固定方式全部做成参数。
7. 不确定的结构必须明确标注为假设，不能伪装成已验证设计。

在建模前，先输出：

- HY928D 图纸尺寸整理。
- 传感器结构理解。
- 可能的固定方式和受力方式。
- 需要人工确认的关键尺寸。
- 结构方案比较。

等待人工审核后再进入详细设计。

## 五、机械设计必须满足的原则

### 1\. 唯一称重路径

杯子重量必须通过预定的传感结构传递。

检查所有可能的旁路：

- 顶板边缘是否碰到底壳。
- OLED 支架是否连接到底壳并承受顶板载荷。
- 螺钉是否形成绕过传感器的受力路径。
- 排线、电线是否跨过浮动间隙并产生额外支撑。
- 装饰件、密封件是否影响称重。

### 2\. 过载保护

设计机械限位结构：

- 正常称重范围内不得接触限位。
- 超过安全位移后由限位结构保护传感器。
- 限位间隙参数化。
- 限位结构不能影响正常测量。

具体间隙应在传感器实际形变和安全位移明确后确定，不要随意给出固定值。

### 3\. 顶板

- 可擦拭。
- 表面平整。
- 杯子放置区域足够大。
- 不容易积水。
- 能够稳定传递杯子载荷。
- 便于拆卸和维护。

### 4\. 底壳

- 稳固支撑传感器。
- 固定 PCB。
- 容纳 ESP32-S3、HX711 和电源。
- 为 USB-C 接口预留开孔。
- 设置防滑脚垫。
- 保证内部零件不会与浮动顶板干涉。

### 5\. OLED 和按键

- OLED 固定在不承重的设计区域。
- 圆形按键位于 OLED 右侧。
- 二者处于前缘同一水平线上。
- 按键有合理的机械行程。
- 按键触发力不能通过非预期路径影响称重。
- 线缆必须有柔性余量，不得限制顶板运动。

## 六、参数化设计

建立统一参数文件，例如：

`config/mechanical_params.yaml`

至少包括：

- 外壳长度、宽度、厚度。
- 外壳圆角。
- 顶板厚度。
- 底壳壁厚。
- HY928D 外形尺寸。
- HY928D 厚度 H。
- 安装孔径和孔距。
- 传感器安装方向。
- 受力接触位置。
- OLED 外形尺寸。
- OLED 开孔尺寸。
- 按键直径。
- 按键行程。
- PCB 外形尺寸。
- USB-C 开孔位置。
- 顶板浮动间隙。
- 过载限位间隙。

未知参数必须设置为待确认状态，不允许凭经验填入最终值。
