## 1. 产品概述

### 1.1 产品定位

智能杯垫是一款用于日常饮水提醒和饮水量估算的桌面设备。

通过称重传感器持续检测杯子及液体重量变化，识别用户饮水事件，估算单次饮水量和全天累计饮水量，并通过设备提示和手机端同步帮助用户形成规律饮水习惯。

产品强调：

- 极简、融入家居和办公环境的外观；
- 无需用户每次手动记录饮水量；
- 基于重量变化估算饮水量；
- 低干扰的提醒方式；
- 设备与手机之间的无线同步；
- 结构简单、可维护、可迭代。

### 1.2 核心功能闭环

```text
杯子放上杯垫
      ↓
识别重量基线
      ↓
持续检测重量变化
      ↓
判断是否发生饮水事件
      ↓
估算本次饮水量
      ↓
更新当日累计饮水量
      ↓
设备提示 / BLE 同步手机
```

## 2. 产品版本规划

### 2.1 普通版：第一阶段开发目标

普通版用于完成完整功能闭环，优先验证称重、事件识别、提醒和手机同步。

当前候选配置：

| 模块 | 方案 |
|---|---|
| 主控 | ESP32-S3 |
| 称重传感器 | HY928D，5kg 量程候选 |
| 称重 ADC | HX711 候选 |
| 供电 | USB-C + 可充电电池 |
| 通信 | BLE |
| 显示 | 小尺寸 OLED |
| 操作 | 一个实体圆形按键 |
| 外壳 | 方形、极简家居风格 |

注意：HY928D 的桥路和电气参数尚未确认，HX711 与传感器的最终兼容性也尚未完成验证。

### 2.2 Solar 版：后续探索

Solar 版不是普通版的简单外壳变体，而是后续独立评估的低功耗版本。

初步方向：

- 无屏幕；
- 低功耗 BLE MCU；
- 光伏供电或能量采集；
- 重新评估称重采样、唤醒策略和能量预算。

普通版的 ESP32-S3、HX711 和电池方案不默认直接复用到 Solar 版。Solar 版在普通版功能闭环验证后再立项。

## 3. 外观与人机交互需求

### 3.1 外观基线

- 外形：正方形；
- 初始外廓：100×100mm；
- 外轮廓圆角：R8；
- 总高度：18mm；
- 配色：白色或浅灰色；
- 风格：极简、克制、适合日常桌面和家居环境。

当前高度构成为：

- 底座：15mm；
- 顶板：3mm。

外观尺寸属于当前 M1.2 设计基线，后续仍可能因结构核实、制造工艺和实物测试而调整。

### 3.2 前缘控件布局

以前缘为 Y 负方向：

- 左侧：圆形实体按键，当前开孔/占位直径 Ø8.2mm，中心 x=5mm（A 版）；**B 版按键 x=17、z=7.2**（与 26×7 屏窗同一水平线）；
- 右侧：小尺寸 OLED；**B 版已改为 0.91" 128×32、窗口 26×7、中心 x=−8**（见 `docs/design/2026-11-04-ui-interaction-b-design.md`）；原 18×7/x=27 为 A 版；
- 两者处于同一水平线，当前设计高度基准 z=8mm。

控件固定于底壳，不与浮动顶板形成连接，也不能成为称重受力路径的一部分。

### 3.3 显示与交互原则

OLED 尽量小，避免破坏杯垫整体外观。

实体按键用于用户主动交互，例如确认、提示反馈或功能操作。按键具体交互逻辑在固件阶段定义。

屏幕内容优先展示少量有用信息，不追求复杂 UI。显示内容和刷新策略应兼顾可读性与功耗。

## 4. 机械结构需求

### 4.1 总体结构

当前采用：

- 底壳；
- 浮动顶板；
- HY928D 应变传感器；
- 四角固定支撑；
- 中央传力结构；
- C 形环绕 PCB；
- 前缘显示与按键；
- 电池及 USB-C 接口。

当前机械设计总高 18mm，顶板厚 3mm，底座高度 15mm。

### 4.2 称重机构

当前方案 A 的设计目标是：

- HY928D 四角固定；
- 中央区域受力；
- 顶板通过传力柱向传感器中央传递载荷；
- 传感器应变后将载荷传递到四角固定支撑；
- 支撑结构最终将载荷传递至底壳和桌面。

设计目标称重路径：

```text
杯子 → 浮动顶板 → 传力柱
     → HY928D 中央受力区域
     → 应变梁 → 四角固定点
     → 底壳 → 桌面
```

该路径是当前 CAD 方案表达的设计意图，尚待依据 HY928D 真实结构和供应商安装要求进行工程核实。

### 4.3 HY928D 当前模型参数

| 项目 | 当前参数 | 状态 |
|---|---|---|
| 外形 | 34×34×1.0mm | 当前模型采用 |
| 外角 | 4-R3 | 当前模型采用 |
| 安装孔 | 4×Ø3.1mm | 当前模型采用 |
| 安装孔位置 | X/Y = ±14mm | 当前模型采用 |
| 孔距 | 28×28mm | 当前模型采用 |
| 中心孔 | Ø5mm | 功能含义待核实 |
| 应变区 | 中央 U 形腔 | 几何细节部分为推算 |
| 梁宽 | 2.5mm | 推算值 |
| 腔宽 | 10mm | 推算值 |
| 腔长 | 29mm | 推算值 |
| 腔深 | 0.7mm | 推算值 |
| 腔内过渡 | 2-R9 | 推算值 |
| 量程 | 5kg | 候选/待实物确认 |

上述参数用于描述当前 M1.2 CAD 模型，不代表传感器实物已经完成测绘。特别是 U 形腔细节、中心孔含义和桥路结构，不得仅凭当前模型认定。

### 4.4 支撑和传力结构

当前方案参数：

| 结构 | 当前参数 | 说明 |
|---|---|---|
| 四角 boss | Ø6，高3mm | 顶面 z=5.0，固定传感器四角 |
| 固定孔 | Ø2.8mm 沉孔占位 | 螺钉方案待确认 |
| 中央垫块 | Ø12，高0.8mm | 作用及接触状态待核实 |
| 传力柱 | Ø6 | 当前设计范围 z=6.0→15.0 |
| 浮动顶板 | 100×100×3mm | 底面 z=15.0 |
| 过载限位间隙 | 0.5mm | 暂定，待形变量和公差核实 |

传力柱端部形状（平底或球头）尚未冻结。中央垫块是否承担预压、防触底或其他功能，也需要根据传感器真实结构重新确认。

### 4.5 唯一称重路径约束

以下结构不得形成顶板至底壳的额外刚性连接：

- 螺钉或铜柱；
- 显示屏及其支架；
- 按键结构；
- PCB；
- 电池；
- 线缆；
- 外壳边缘或装配限位面。

过载限位允许在达到规定位移后接触，但正常称重行程内不得提前接触。线缆应留有运动余量，不能跨越浮动间隙形成支撑。

### 4.6 C 形环绕 PCB

当前 M1.2 空间方案：

| 项目 | 参数 |
|---|---|
| 板形 | 内腔 93.2×93.2mm、R6 |
| 中央开口 | 38×38mm 方形 |
| 前缘开口 | 70° C 形缺口 |
| 板厚 | 1.6mm |
| 层级 | 与传感器同层，z=5.0mm |

器件占位：

| 器件 | 当前空间位置 |
|---|---|
| ESP32-S3 | 18×25mm，后右区域，约 (32,31) |
| HX711 | 12×15mm，右侧区域，约 (36,0) |
| USB-C | 8.94×7.5mm；A 版前右侧 r≈40/320°；**B 版改为后缘居中（x=0, y≈+43.75）**，见 `docs/09_Assembly.md` |
| 电池 | 25×30×5mm，后左区域，约 (-32,24)，z=6.6mm |

中央开口采用方形 38×38mm，与 34×34mm 方形传感器对应，单边名义间隙 2mm。该开口不是圆形。

当前电池位于 PCB 上方，属于空间占位方案。电池固定、绝缘、热安全、连接器和线缆布置尚未完成设计。

### 4.7 结构防护与制造

- 顶板表面应便于日常擦拭；
- 不要求整机浸水；
- 结构应适合 3D 打印原型；
- 关键螺钉柱、壁厚和装配间隙需在 M2 进一步核实；
- 后续量产工艺和材料选择不在 M1.2 冻结范围内。

## 5. 电子系统需求

### 5.1 系统组成

```text
HY928D
   ↓
HX711（候选）
   ↓
ESP32-S3
   ├── OLED
   ├── 实体按键
   ├── BLE
   ├── 电池管理 / 电量检测
   └── USB-C 供电与充电
```

该框图是功能架构，不代表电路原理图已经完成。

### 5.2 HY928D 电气参数待确认

当前参数手册列出的候选信息：

- 量程：5kg；
- 全桥灵敏度候选：1.2mV/V；
- 半桥灵敏度候选：0.6mV/V；
- 激励电压候选：3–10V；
- 阻抗候选：1kΩ±10%；
- 线色候选：红色 E+、黑色 E−、绿色 S+、白色 S−。

以上桥路、灵敏度和引线定义必须以供应商资料或实物测量为准。不得默认 HY928D 为全桥，也不得仅凭线色确定接线。

### 5.3 HX711

HX711 是当前候选称重 ADC。

需要结合 HY928D 最终桥路确认：

- 输入接法；
- 激励供电；
- 是否需要补桥；
- PGA 增益；
- 输出采样速率；
- 电源与模拟地布局；
- 噪声、漂移和稳定时间。

HX711 的具体配置应在传感器电气参数确认后冻结。

### 5.4 电源与电池

普通版采用 USB-C + 可充电电池的设计方向。

需要进一步设计：

- 充电管理；
- 电池保护；
- 供电路径；
- ESP32-S3 与 HX711 的电源域；
- 待机功耗；
- 电量检测；
- 低电量提示；
- USB-C 插拔空间与机械固定。

当前 M1.2 仅完成电池空间占位，未完成电源电路和安全设计。

## 6. 固件与算法需求

### 6.1 称重数据采集

固件需要完成：

- HX711 数据读取；
- 上电稳定与初始化；
- 零点校准；
- 滤波与异常值处理；
- 空杯/有杯状态判断；
- 杯子放置和拿起检测；
- 稳定重量基线维护。

### 6.2 饮水事件识别

核心逻辑：

1. 识别杯子稳定放置；
2. 建立当前重量基线；
3. 检测持续的重量下降；
4. 区分饮水、拿杯、移动杯子和外部碰撞；
5. 判断事件结束；
6. 估算本次饮水量；
7. 更新累计饮水量。

饮水量估算以重量变化为基础，初期可按水的质量与体积近似换算。算法需要处理杯子本身重量、加水、补水、移动和重新放置等状态。

### 6.3 提醒逻辑

- 支持按时间间隔提醒；
- 用户主动饮水后可调整下一次提醒；
- 避免短时间重复提醒；
- 提醒方式应低干扰；
- 后续允许通过手机端调整提醒策略。

提醒策略的具体时间间隔和用户配置方式待固件阶段定义。

## 7. 手机端需求

普通版通过 BLE 与手机同步。

第一阶段手机端功能：

- 设备发现与连接；
- 当前杯子重量或饮水状态；
- 单次饮水量；
- 当日累计饮水量；
- 历史记录；
- 提醒配置；
- 设备电量与连接状态。

优先完成核心数据同步，不在第一阶段引入复杂云服务或账号体系。数据存储策略和跨设备同步需求后续再评估。

- 能够估算单次和每日饮水量；

### M5：样机验证

- 记录失败案例并迭代设计。

### M6：迭代与产品化评估

根据样机结果决定是否调整：

- 结构尺寸与材料；
- 传感器和 ADC；
- 低功耗策略；
- 外观和交互；
- 生产工艺；
- Solar 版可行性。

## 10. 当前执行计划

项目当前处于 M1.2 → M2 的转换点。

下一步优先级：

1. 保留 M1.2 Git 版本和完整设计源。
2. 整理 HY928D 供应商问题清单，优先确认中心孔、U 形腔、桥路、灵敏度和额定形变量。
3. 根据确认结果修订传感器模型和传力结构。
4. 对称重路径、浮动间隙和过载限位做工程核实。
5. 完成 PCB 固定、电池固定、USB-C 开窗和线缆隔离设计。
6. M2 评审通过后，再开始 M3 电路设计。

**阶段原则：先证明称重机构成立，再把电子系统固定到结构中；先完成普通版闭环，再考虑 Solar 版。**
