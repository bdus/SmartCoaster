# Workflow: Appearance Variants (A0–A2)

> 门禁：`gates/appearance.yaml`（G-APPEAR）· 前提：机械功能基线已冻结并通过 G-MECH
> 核心：**只改外皮，不动功能区；每个变体做不变量 diff（容差 0）**。

## 1. 阶段表

| 阶段 | 输入 | 动作 | 输出 | 证据 / 门禁 |
|---|---|---|---|---|
| A0 冻结 | M3 模型、电子占位、用户外观指示 | 冻结功能区、列出允许变化轴 | 冻结清单 + 基线不变量 JSON | 清单完整、无歧义 |
| A1 变体 | A0 | 拆 `build_internals()`（冻结）+ `build_skin(params)`；只改外皮/CMF | 变体 STEP/STL/渲染 | 功能区 diff = 0 |
| A2 验收 | A1 | 21 项功能自检 + 外观专项 + 渲染一致 + 独立复核 | 验收 JSON/MD/图 | G-APPEAR 全绿 |

## 2. 冻结清单（必须原样继承，本项目示例）

| 类别 | 冻结项 |

| 称重 | HY928D 34×34×1.0 @z5；4 角 boss Ø6；Ø3.1 @28×28；中心 Ø5 |
| 传力 | Ø6 柱 z6→15；中央垫块 Ø12×0.8 |
| 限位 | 0.5 mm 处壳口先接触（≈7.28 kg） |
| 电气 | PCB 93.2×93.2×1.6、R6、38×38 开口、80° C 口、4×M2 @(±40,±24) |
| 显示 | 26×7 窗 @x=−8 / z=8.0；可视区 22.4×5.6 无遮挡 |
| 按键 | Ø8.2、x=17、z=7.2；行程无遮挡 |

## 3. 允许变化轴

外轮廓（方形 R8 / 方圆 R20–R40 / 倒角 / 胶囊，≤110×110 包络）、顶板材质/CMF、
窗 bezel/玻璃、按键帽、底壳腰线/垫脚、logo/纹理、包装图形。

## 4. 每变体验收流程

1. **不变量 diff**：与基线比功能区坐标（传感器/boss/传力柱/PCB/电池/OLED/按键/USB-C），容差 0。
2. **功能自检**：复用 21 项（浮 0.5 / 行程 / 限位 / 37 对干涉 / STEP 回读）。
3. **外观专项**：窗可视区/视角、按键可达、USB-C 插头空间、天线净空、包络/包装、桌面稳定、清洁可达。
4. **渲染**：同一版 STL + CMF 出 hero/front/exploded，记录 `RENDER_LOG.md`。
5. **独立复核**：verifier 只读复跑。
6. **文档**：更新 CMF/路线图/HANDOFF/README 并 commit。

## 5. 已知失败模式

| 现象 | 根因 | 预防 |
|---|---|---|
| 外观变体破坏称重 | 外皮碰浮动板/传力/限位 | 冻结清单 + 每变体不变量检查 |
| 真圆装不下 | 未先算包络 | 先算 PCB 对角线（131.8 > Ø110）→ 另立项 |
| 旧概念当基线 | LUMEN 含光导/LED/0.49" 屏/无按键 | 明确标 legacy，仅作形态参考 |
| 图与文档不一致 | 改外观没重出全套资产 | 变更传播清单 + 时间戳 |

## 6. 边界

- 外观变体不证明新的称重性能；开槽/结构改动必须重跑 G-MECH 与 FEA。
- 本项目 B/C/D 变体处于计划阶段（status not_run），CMF 4 变体已完成。
