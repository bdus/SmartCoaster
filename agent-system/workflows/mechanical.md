# Workflow: Mechanical (M0–M3)

> 门禁：`gates/mechanical.yaml`（G-MECH，21 项）· 唯一来源：`mechanical/<version>/cad/<model>.py`
> 本文件 = 每个阶段 input → action → output → evidence/gate + 复用清单 + 失败模式。

## 1. 阶段表

| 阶段 | 输入 | 动作 | 输出 | 证据 / 门禁 |
|---|---|---|---|---|
| M0 设计输入 | PRD、传感器图纸、参考拆解、照片 | 结构方案、受力路径、参数清单、未确认项 | `docs/design/*`、`config/mechanical_params.yaml` | 参数清单完整；无最终外壳 |
| M1 关键结构 | M0 参数、安装方案决策 | 传感器参考模型、安装接口、浮动/传力/限位 | 关键结构 STEP/STL | G-MECH（早期） |
| M2 完整建模 | M1 + 电子占位 | 全部零件、C 形板占位、屏窗/按键/USB-C | `build/parts/*.step|stl`、装配 | 单实体/bbox/valid |
| M3 机械验证 | M2 模型 | 跑自检；STEP 回读；FreeCAD 独立复核 | `verify_report.json`、`verify_v01.log` | **G-MECH 21/21** |

## 2. 关键动作顺序

```text
参数表（唯一来源）
  → build_assembly() 返回 (assy, parts, rows)
  → 自检：实体数/bbox/valid/单实体
  → 功能几何：浮动间隙/传力柱/裙边/PCB 开口/电池/OLED/按键
  → 行程：顶板下行 0.5 mm 无遮挡
  → 传感器柔度：用 S1 刚度算 5 kg 下沉与剩余间隙
  → 过载限位：0.5 mm 处壳口先接触，≤150% 载荷
  → 干涉：37 对关键零件两两求交 == 0
  → STEP 导出后回读：实体数 + bbox
  → 落 JSON（ok + 逐项 check/detail）
```

## 3. 复用清单（新项目逐条替换）

- [ ] 参数表：总尺寸/壁厚/浮动/传感器/PCB/屏窗/按键/USB-C。
- [ ] 零件列表与材质表（材质与 CMF/质量/天线自洽）。
- [ ] 唯一载荷路径（画出来）+ 旁路黑名单。
- [ ] 自检阈值：剩余间隙、过载接触载荷、干涉对数、STEP 回读。
- [ ] 传感器刚度来源（FEA 结果 JSON，假设变了重算）。
- [ ] 版本快照（agentcad/ git tag）。

## 4. 已知失败模式（本项目真实踩过）

| 现象 | 根因 | 预防 |
|---|---|---|
| 几何不干涉但称重不成立 | 没检查唯一载荷路径/旁路 | M3 单独做行程 + 旁路检查 |
| 5 kg 剩余间隙算错 | 用了旧 FEA 刚度或手算 | 引用同一版 S1 结果 + 阈值来源 |
| 装配图/渲染还是旧版 | 只改模型没重导出 | 改源后 STEP/STL/GLB/渲染全重跑 |
| 圆形外壳装不下方形板 | 没先算包络 | 先算对角线（93.2→131.8 mm） |
| PROVISIONAL 尺寸被当真 | 没进 config/status | 双标注 + config 登记 + 报告注明 |

## 5. 边界

- 21/21 只证明**几何/装配/行程/干涉**；强度/称重精度归 S1 FEA 与实物标定。
- FEA 网格/材料/边界假设变了，机械自检里的"传感器柔度"结论作废，必须重算。
