## 2. S1 可执行流程（HY928D 实例）

```text
1. 冻结模型 STEP（只读）
2. gmsh -3 -order 2 -clscale ... -format inp
3. 材料 65Mn：E=210000 MPa, ν=0.3, ρ=7.85e-9 t/mm³
4. 边界：四角孔 ±2.2 mm 夹紧区 ENCASTRE（假设 A）
5. 载荷：49.05 N，−Z，顶面 r≤4 均匀（一致节点力，合计精确）
6. ccx -i case（*STATIC 线性）
7. 提取：中心 |Uz|、max von Mises 及位置、支反力合计、热点
8. 对比：通槽 vs 0.7 mm 浅腔
9. 产物：inp/msh/frd/results*.json/figs/README
10. 验收：支反力=载荷±2%；剩余间隙>0；网格收敛差<10%
```

## 5. 已知失败模式

| 现象 | 根因 | 预防 |
|---|---|---|
| 仿真"通过"但芯片指标未知 | 行为模型当芯片级 | 报告写模型等级与不能证明 |
| 网格越细越准？ | 尖角奇异不收敛 | 报告区分奇异点 |
| 只看图不看数 | 判据在图上 | 指标落 JSON |
| 阈值是 null 还写通过 | 无来源 | 无来源只能"记录" |
| 假设变了不重跑 | 结论过期 | 假设进报告 + 变更作废 |
