## 2. 参数联动（工程要求，不是建议）

```text
色数 N → 层数 N → 印花厚度 = N × 层高(0.20)
       → 槽深 = 厚度 + 0.05
       → 顶板剩余肉厚 = 顶板厚 − 槽深
```

- 印花直径 `Ø86.4`（576 px × 0.15 mm）；槽 `Ø86.0`；名义过盈 0.20 mm（最大 0.288）。
- 印花顶 = 沿口 − 0.05 mm；槽底 = 平面度 0 并作为印花 Z 基准。
- 加/减一种耗材 = 厚度/槽深各 ±0.2 mm，顶板余厚 ∓0.2 mm，必须同步改。

## 3. 多材料与交付规则

- 外壳与印花**不做布尔合并**；3MF 里 = 1 个装配对象 + 每耗材 1 个 component。
- **三角面不得去重**（反向绕序界面面是闭合材料件的正常表示）。
- 交付真实 STL：外壳/开槽顶板/按键/印花逐耗材；每个 sha256 == 源。
- STL 不带材料信息：逐耗材多文件同时导入，逐对象分配 AMS；推荐 `PRINT_READY.3mf`。
- 打印路线 A（顶板凹槽朝上 + 印花嵌槽同盘，需支撑）/ B（顶板倒扣 + 后装压配）。
- 6/7 色需 ≥6 槽位；4 槽需换料或第二台 AMS，或压到 4 色（同步改槽深）。

## 4. 复用清单

- [ ] 素材是椭圆时按椭圆包围盒重采样回正圆。
- [ ] 量化到**固定耗材色板**（可复现），不是 k-means 平均色。
- [ ] 层高与切片层高一致；像素尺寸 < 喷嘴线宽但注意打印精度下限 0.45–0.6 mm。
- [ ] 从已验证 STEP 导入切槽，不重建外壳。
- [ ] 3MF/Bambu 元数据：只写通用 3MF，AMS 由用户分配。
- [ ] 大文件（STL/STEP/3MF/blend）脚本可再生成，默认不入 git。

## 5. 已知失败模式

| 现象 | 根因 | 处置 |
|---|---|---|
| 3MF 比 STL 少 26 万面 | 误删反向绕序界面面 | 禁止去重；component 三角数断言 |
| 圆形槽深对不上圆柱体积（−19.5%） | 源板内部空腔本是空气 | 用槽底以上实际材料对账 |
| STEP≠STL | 源顶板建模缺陷（2-shell 空腔） | 记录 + fill 变体；不改源 |
| 印花椭圆/尺寸偏 | 源图是椭圆 | 椭圆包围盒重采样 |
| 渲染微距全黑 | clip_start > 微距距离 | clip_start=1 mm + 长焦 |
| AppImage 直接跑崩 | 没走 AppRun 库路径 | 用启动器/AppRun |
| 打印位置/尺寸错 | 导入后缩放/镜像 | 禁止缩放/镜像 |

## 6. 边界（必须写进报告）
