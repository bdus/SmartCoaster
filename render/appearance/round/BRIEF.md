## 2. 外观两条产品线

### L1 · Pure（纯色）
暖白 PC/ABS 细磨砂，无图案；靠比例、浮缝、浅碟和双微凹控件区立住。
目标：像一件桌面摆件，而不像小家电。

### L2 · IP（联名）
**两条 IP 都做平面印花**，不做浮雕；与纯色款共用同一套壳体/顶板几何，只换印花。

- 印花面：**顶板杯外环带**；Ø85 杯会盖住中心，可印区是 Ø85–Ø104 的 **9.5 mm 环带**，前弧最可见。
- 图案尺寸：主图 **6–8 mm**（环宽限制），前弧放一个主图 + 两侧小星点/爪印；也可做整圈重复小图（4–6 mm）。
- 颜色：单色、低饱和主题色（每张 IP 一个颜色；具体色值等参考图确认）。
- IP 分配：芙莉莲、线条小狗各出一款印花；图形等用户发参考图/授权素材。
- 无独立壳模，打样/量产成本与纯色款接近。

> ⚠️ 芙莉莲与线条小狗均为第三方 IP：量产需授权。本轮只做**位置/比例/画风**概念稿，正式图案必须用授权素材替换，不直接复制官方图。

## 3. 形态研究结论（已渲染）

`render/appearance/round/00_front_treatment_compare.png`：

- **A · 单条控制带**（54×9.6 凹槽，深 4.5 mm）：整体感强，但阴影重、容易被读成“嘴”，密封/开模最简单。
- **B · 双微凹**（屏凹 3.2 mm + 按键 Ø11 圆台）：更接近“微凹平面”，两个控件各自独立，圆感保留更好。**已选 B**。

四视图（暖白纯色）见 `00_solid_warm_white.png`。

## 4. 圆形机械基线的改动（下一步工作，尚未执行）

以 LUMEN（`mechanical/lumen/`，Ø110×17，13 件）为起点：

1. 去光导 `guide`、去 LED flex → 零件数下降；
2. 前脸改双微凹：屏凹 + Ø11 按键圆台 + 26×7 胶囊窗；
3. 新增 Ø8.2 实体按键（同色哑光）；
4. PCB 改圆形 C 板（Ø102）：当前方形 93.2 板对角线 131.8 mm 放不进 Ø110，**必须重排**
   （2 层、43 器件、ERC/DRC/DFM/装配图/坐标都要重跑）；
5. 包装内衬改圆腔（外箱 120×120×36 可沿用）；
6. 复跑 21 项几何/行程/干涉自检 + STEP 回读；
7. 重新冻结几何哈希（新 `frozen_geometry_round.sha256`），之后只改外观。
