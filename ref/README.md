## 读图工作区

`ref/.work/` 保存了从原图裁切/放大的局部图（U 形槽、表格、技术要求），方便复核；不是设计源。

## 三条最重要的结论

1. **HY928D 是"四角固定 + 中央受力"的 U 形梁式**（图纸 4 孔 + 中央 Ø5 + 4 片应变片），不是参考产品的单点式 SC134。
2. **U 形槽是通槽还是浅腔、槽深/梁宽/内圆角，图纸没有剖视**；M1.2 的 29×10×0.7 是反推值，必须向供应商确认或剖开实物。
3. **参考产品值得学的是包装与交互**（浮动顶板、环形 PCB、前缘屏+多键、灯环、100 ms 状态机），不是它的单点传感器安装方式。
